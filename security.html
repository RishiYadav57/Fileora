Document Security & File Handling

Understand exactly how your documents are isolated, parsed, transformed, and cleaned up across our client-first and server-assisted pipelines.

The End-to-End Processing Lifecycle

01

File Selection

Document loaded into browser sandboxed memory via HTML5 File API. No remote transfer initiates.

02

Client First

Local JavaScript parser reconstructs document layout, fonts, and tables right in your device RAM.

03

Server Fallback

If complex compiler libraries are required, file streams over TLS 1.3 to transient memory.

04

Instant Download

Transformed Blob URL initiates native browser download immediately.

05

Immediate Purge

Blob URLs revoked in browser. Server temporary files unlinked via safeUnlink() immediately.

In-Browser Sandboxed Execution

Tools such as Word to PowerPoint, PowerPoint to Word, ZIP Files, UNZIP Archive, Merge PDF, Split PDF, Remove Pages, and Add Watermark execute entirely in client-side WebAssembly and JavaScript libraries. Because processing occurs inside your browser's sandboxed tab memory, document contents are never transmitted across the network.

Zero Persistent Storage Policy

Fileora runs with zero persistent document storage. There are no relational databases indexing file contents, no permanent S3 buckets holding past conversions, and no user profile directories. Once your output file finishes downloading, all associated memory is released.

AI Processing & Privacy Guarantees

For AI Summarizer and Document Translation, text or page renders are sent over TLS 1.3 to Google Gemini API. This data is processed strictly in runtime to generate the executive summary or language translation and is not logged, stored, or utilized for model training.

Password Security & Decryption

When using Protect PDF, encryption occurs using standard 128-bit/256-bit AES algorithms. When using Unlock PDF, the password you provide is verified strictly in ephemeral memory to remove permission flags. We never log or store user passwords.

Recommended User Security Precautions

While Fileora minimizes risk through client-side architecture and zero persistent storage, you should practice standard document security hygiene:

  • Always clear your local browser cache when using public or shared computers.
  • Do not transmit passwords or sensitive credentials in unencrypted channels.
  • For documents containing extreme national security or regulated secret credentials, prioritize fully offline air-gapped workstations.
