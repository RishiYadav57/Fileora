Diagnostic Procedures & Error Fixes

Conversion & Upload Troubleshooting Guide

Step-by-step diagnostic sequences for resolving formatting distortion, broken tables, unexpected line spacing, and file size bottlenecks.

1 Conversion Button Shows "Working..." or Appears Stuck

Execution Flow

Likely Cause: If a document has several hundred pages, client-side memory parsing takes more CPU cycles, or the backend server fallback is waking up from idle sleep.

Troubleshooting Sequence:

  1. Click the Clear All button or the ✕ icon to immediately abort the ongoing task without freezing your browser.
  2. If your PDF exceeds 200 pages, use the Split PDF tool to break it into targeted chapters before converting to Word.
  3. Check that you have not opened dozens of memory-heavy browser tabs concurrently.

2 Tables Damaged, Columns Shifted, or Borders Missing

Layout Engine

Likely Cause: The source PDF has borderless tables, irregular nested cell spans, or was generated from an image scan without digital vector cell lines.

Troubleshooting Sequence:

  1. Verify whether text in the source PDF is selectable with your mouse cursor. If you cannot select text, the document is an image scan.
  2. For tabular spreadsheets, run PDF to Excel rather than PDF to Word; the Excel engine uses dedicated 2D grid line clustering.
  3. If cells merge unexpectedly, open the exported DOCX in Microsoft Word and use Table Layout › Distribute Columns Evenly.

3 Text Overlaps, Abrupt Font Changes, or Double Line Gaps

Typography

Likely Cause: PDFs define each physical text segment at specific XY coordinates. If lines are not grouped as paragraph continuations, each line receives default Word paragraph spacing.

Troubleshooting Sequence:

  1. Ensure you are using the latest version of FileCorner; our engine automatically clusters continuous lines using paragraph margin continuation logic.
  2. If custom fonts render differently, install the font family (e.g., Aptos, Calibri, Montserrat) locally on your operating system so Word can match glyphs.

4 Error: "File is Password-Protected"

Security Flags

Likely Cause: The document has encrypted permissions or an owner password preventing extraction of text and graphics.

Troubleshooting Sequence:

  1. Switch to the Unlock PDF tool in our top navigation bar under PDF Tools.
  2. Enter the document password to decrypt the permissions envelope.
  3. Once downloaded as an unlocked PDF, upload the unlocked file to PDF to Word, PDF to Excel, or Merge PDF.

5 Download Notification Shows But File Does Not Save

Browser Download

Likely Cause: Your browser blocked automatic multi-file downloads or prompt popups.

Troubleshooting Sequence:

  1. Check the top-right corner of your screen for the floating File Downloaded notification toast.
  2. Click the blue link: "Tap here if download didn't start" to manually trigger the download buffer.
  3. Check your browser URL bar for a blocked popup icon and select "Always allow downloads from this site".
