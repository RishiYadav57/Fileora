2. Categories of Information Processed

We strictly limit information processing to what is technically necessary to perform your requested document conversions, enforce security safeguards, and deliver downloads:

A. Uploaded Files and Generated Outputs

When you select a document, presentation, spreadsheet, image, or archive (e.g., PDF, DOCX, PPTX, XLSX, JPG, PNG, ZIP), the file bytes are transmitted to execute the requested transformation (e.g., Word to PDF, PDF to Word).

B. Document Metadata & User Conversion Parameters

We process original filenames, sanitized output names, file sizes, MIME types, and tool parameters you explicitly provide (such as passwords for protected PDFs, custom watermark text, image quality presets, or target translation languages).

C. Job Identifiers and Download Security Tokens

Each conversion job generates a random 128-bit Job ID (e.g. cjob_...) and a cryptographically randomized 256-bit token. The token must be presented to download the converted file, preventing unauthorized third parties from guessing or accessing your file.

D. Security & Infrastructure Telemetry (IP Addresses)

Client IP addresses are evaluated in server volatile memory to enforce strict abuse-prevention policies: a rate limit of 120 requests/minute and a concurrency limit of maximum 2 simultaneous conversions per user/IP. IP addresses are not compiled into user tracking profiles.

E. Voluntary Communications

If you send an email to pdfconverterfreebusiness@gmail.com or submit a message through our Contact form, we receive your name, email address, category, and message text to respond to your technical support or privacy inquiry.

3. Purposes and Legal Bases for Processing

We process your data strictly on the following lawful grounds:

  • Service Execution (Contractual / Requested Service): Processing files, extracting tables, rendering formats, and delivering download streams requested by you.
  • Security & Abuse Prevention (Legitimate Interest): Inspecting magic byte signatures to block spoofed executables, screening ZIP archives against decompression bomb exploits, rate limiting, and restricting concurrency.

5. Google Gemini AI Feature Disclosures

FileCorner integrates the Google Gemini API to power three optional intelligence tools:

  • AI Summarizer: Generates executive briefing summaries from document content.
  • Translate PDF: Translates document text into over 20 languages.
  • PDF to Excel Table Extraction: Locates tabular patterns in extracted text.

What Leaves Your Device When Using AI Features:

When you invoke an AI tool, we extract the document's raw text (truncated to maximum 150,000 characters) and/or up to 12 rendered page image snapshots (for scanned/diagrammatic documents), and transmit them via HTTPS to the Google Gemini API endpoint (generativelanguage.googleapis.com).

Your raw original file is NOT uploaded to Google. Standard conversion tools (Word to PDF, PDF to Word, PowerPoint, Excel, JPG, Compress, Merge) run entirely on local headless engines and never interact with Gemini.

Applicable Google Gemini Terms & Data Governance:

Google's processing of data sent to the Gemini API is governed by the Google Gemini API Terms of Service and Google's general Privacy Policy:

  • Free Tier Usage: Under Google's free tier API terms, submitted prompts, responses, and related materials may be processed by human reviewers and used by Google to train and improve Google models and products.
  • Paid Tier Usage: When paid billing is active on the API project, customer data is not used to train Google machine-learning models.
  • Recommendation: Because API billing tiers depend on the Google Cloud project configuration, we advise visitors not to submit sensitive personal, legal, financial, or confidential information to the AI tools.
