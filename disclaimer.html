2. Technical Conversion Fidelity Disclaimers

File format conversion involves translating proprietary, complex data structures (such as Microsoft Office binary/XML formats, Adobe PDF specifications, and open image standards) across different parsing engines. Users must be aware of the following technical realities:

Fonts and Typography Rendering

If your original document utilizes custom, unlicensed, or non-standard fonts not installed on the server environment, the conversion engine will automatically substitute the closest matching open-source typeface (e.g., Liberation Sans or Noto Sans). This may cause text reflow, line wrap alterations, or subtle page count changes.

Spreadsheets, Tables, and Wide Layouts

Converting spreadsheets (Excel XLSX/CSV to PDF) requires dynamic page pagination. While our layout engines apply intelligent landscape orientation and column scaling, sheets with vast numbers of columns, hidden formulas, linked external data sources, or active macros cannot be guaranteed to replicate the exact visual pagination of desktop Excel.

Lossy Image & Document Compression

Document and image compression tools reduce file sizes by re-encoding raster imagery and pruning unneeded metadata. Aggressive compression settings may result in perceptible visual artifacts or color alterations.

OCR (Optical Character Recognition) & Scans

OCR text extraction from scanned PDFs depends heavily on image clarity, lighting, skew, and resolution. OCR is inherently probabilistic and cannot guarantee 100% character precision, especially on cursive, handwriting, low-contrast, or degraded scans.
